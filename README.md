# Checker's Tool

Windows desktop checking utility for EPIC spooling workflows.

## Current version
V1.0.43

## Update channel
Stable releases are distributed through GitHub Releases. The desktop application checks the latest release configured centrally in Supabase.

## V1.0.43
- Automatic Windows/system identity registration
- No username/password login or admin approval
- One-year registration validity
- Severity-colored large announcement popups
- GitHub release update support

Do not commit Supabase service-role keys, GitHub PATs, passwords, local registration tokens, caches, or logs.
